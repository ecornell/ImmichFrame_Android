## Changes since v74

Review fixes and a refactor:

- The wake alarm is exact only when Android allows it (API 31+), otherwise `setAndAllowWhileIdle`.
- MQTT publishes the newest state rather than a listener's copy, and stops and starts on its own
  thread instead of the main thread.
- RPC allows at most 8 concurrent connections and closes any connection whose request body was
  left unread (an unread legacy POST body used to be parsed as the next keep-alive request).
- Waking restores the brightness requested remotely.
- Rotation, keyboard, uiMode and locale changes no longer recreate the Activity.
- The cold-start cached image is read off the main thread, WebView retries are cancelled with
  their page, and the video player is released off the main thread.
- R8 keeps only reflected classes (affects the `frame` build type only, not this debug build).
- The native slideshow, overlays, WebView presentation and preferences moved out of MainActivity
  into shared classes that the screensaver now also uses. The screensaver gains the clock tick,
  weather redraw, decoded-image pipeline, single-thread rendering and retry backoff.
