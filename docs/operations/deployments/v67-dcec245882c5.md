## Changes since v65

Bug fixes from the earlier code review:

- Back-to-back videos crossfade instead of cutting, a finished video no longer replays on resume, and an interval change reschedules after a video ends.
- The settings lock cannot be enabled without authenticated remote control, and dismissing its confirmation reverts it. A client over the RPC failed-auth limit is refused before its token is compared.
- Renderer: the never-visible full-screen split gap fill is removed (the darkened-average divider is kept), the blur stage keeps the slot's aspect ratio, sub-pixel gaps snap to the slot edge, and the blurred backdrop is dithered.
- Both WebView clients retry only failed page loads; opening a link tolerates a missing browser. The screensaver reads its cached image off the main thread, stops toasting every HTTP retry, and drops a no-op wake lock. `CachedImageStore.readPrepared` no longer re-encodes a binary entry that fails to decode.
- Cold start loads settings once, with Active Times on or off. The offline indicator clears when the server returns settings, and a local render failure no longer raises it.

v66 (`v66-3457fa949d85`) was installed on the WF1561 first. A cold-start profile showed `loadSettings`, `createRetrofit` and `getServerSettings` still running twice because the WF1561 has Active Times on; v67 fixes that path and superseded it.
