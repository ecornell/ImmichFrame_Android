## Changes since v61

Fixes from a four-part code review:

- Only the upper image view fades during a crossfade, removing a darkening of about a quarter at the midpoint.
- The remote (RPC/MQTT) paused state follows the image timer; it was inverted from boot.
- A server URL without a scheme reopens settings instead of crash-looping the HOME app.
- The first MQTT connection is retried with backoff.
- The slide interval restarts when a photo is presented.
- Widget decode failures are caught.
- Prefetch runs at a lower nice value outside the background cgroup.
- Explicit images render on the slide thread.

GPU work: the window background, crossfade and zoom hardware layers are removed, rendered frames start their texture upload on the worker, and the Ken Burns zoom is driven by Choreographer.
